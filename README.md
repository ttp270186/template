# Techniques
The mostly prefer techniques that I have recently learnt is: non-blocking technique, which was introduced originally by Node.js. Non-blocking io was firstly applied for Java in Spring 5.0 framework - of course, I am talking about Spring webflux module in Spring family.
In additional, Spring 5 also has introduced some libraries that support reactive access to non-relational DB like Cassandra, MongoDB, Couchbase, then the final piece for relational DB is: R2DBC(Reactive Relational Database Connectivity).
